# Four problems with an independent examiner

Date: October 30, 2026. **Research only; the live MathPDF application and prompts were not modified.**

## Result

Four new problems were generated by `gpt-4.1-mini-2025-04-14` using the isolated validity-first candidate. `gpt-4.1-2025-04-14` then performed two examinations:

1. A fresh request containing the source and **only the statements**, without the generator's answers.
2. A separate request containing the original statements, proposed solutions, source, and the prior examination.

The model accepted all four solutions. A subsequent local check identified a missed algebraic error in problem 2:

```text
(x² - 1) / x = x - 1/x       (x != 0)
```

The generated solution incorrectly adds an extra one. At `x=2`, the true value is `3/2`, while its claimed simplification is `5/2`. The blind examiner also incorrectly states that the two functions coincide on their common domain. The final conclusion that the functions are unequal is true, but those intermediate arguments are not.

**Therefore this run does not validate automatic acceptance by a second model.** It demonstrates a concrete false acceptance. It also does not establish statistical error rates from a four-task sample. Novelty labels are model opinions: changing a source exercise's numbers or formula is not by itself proof of substantive novelty.

Total generation/review usage cost: **$0.0480796**, approximately 4.8 cents. Three paid generation/review calls; no retries and no automatic corrections. Three input-count requests were made before the calls. Prices used per million input/cached/output tokens: mini `0.40/0.10/1.60`, GPT-4.1 `2.00/0.50/8.00`. These are calculations from response usage, not a billing-balance audit.

## Reproduce safely

Use the existing MathPDF Python environment for the read-only schema imports. Supply your own source and credentials in the environment or ignored metrics `.env`:

```sh
python -B experiments/review-four/experiment.py --stage generate --source /path/to/main.pdf --mathpdf-source /path/to/mathPDF --execute
python -B experiments/review-four/experiment.py --stage blind --source /path/to/main.pdf --mathpdf-source /path/to/mathPDF --execute
python -B experiments/review-four/experiment.py --stage audit --source /path/to/main.pdf --mathpdf-source /path/to/mathPDF --execute
```

The script is resumable but refuses to repeat reserved/completed stages. It allows at most three calls and reserves input cost plus maximum output before each call against a local `$0.10` budget. Input tokens receive 10% headroom; this is a request-level safeguard, not an account-wide billing cap. An unknown failed request retains its reservation. New models/rates require explicit changes to the experiment, not silent substitution.

`publish_result.py` creates the public `result.json` and `reviews-data.js` snapshot without any API calls. It does not change the historical flashcard dataset or browser-local backups.

The website uses the read-only MathPDF math-rendering component and vendored KaTeX for presentation. KaTeX licensing is retained under `vendor/katex/LICENSE`. Displayed model acceptance and local mathematical findings remain separate.
