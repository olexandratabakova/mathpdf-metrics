- Functions: check the formula defines a value in the stated codomain for every domain input. For injectivity, justify transformations and excluded denominators. For surjectivity, start with an arbitrary target in the ORIGINAL codomain, construct a preimage and verify it lies in the ORIGINAL domain. - Function equality: compare domains, codomains when required by the source's definition, and values. Do not ignore excluded points. Exponential surjectivity needs the actual function rule and domain, and a valid preimage for every positive target; monotonicity alone proves neither the range nor surjectivity.
- Induction and integer constructions: test the claimed starting value and nearby values before writing the proof. State the integer convention, including whether zero is allowed. Prove sufficient base cases for the chosen step size and give the full transition with its conditions. Several verified examples are not a proof for all integers. - Divisibility, parity and counterexamples: check EVERY hypothesis and EVERY part of the negated conclusion. To refute an implication whose conclusion is a disjunction, both disjuncts must be false. An integer witness must expand to the stated expression. An inequality chain must have every comparison valid. Do not retain a false equality followed by a different argument.
- Inverse set problems: establish existence and uniqueness under the stated hypotheses. Reconstructing a second Cartesian factor requires a nonempty known first factor unless the question explicitly studies non-uniqueness. Preserve the source's subset convention.

These are checking rules, not a requirement to generate all these topics. Use only methods supported on the selected pages. Small boundary checks help detect counterexamples but do not by themselves establish a universal theorem.
